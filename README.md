# Zomato Analysis Dashboard

## **Project Overview**

This project focuses on analyzing Zomato restaurant data using Microsoft Power BI. The dashboard presents restaurant-related insights through interactive visualizations.

## **Tools Used**

- **Microsoft Power BI**
- **Data Analysis**
- **Data Visualization**

## **Key Features**

- **Total Restaurants**
- **Restaurant Distribution by City and Country**
- **Top 10 Cuisines**
- **Restaurant Rating Analysis**
- **Price Range Analysis**
- **Online Delivery Analysis**
- **Table Booking Analysis**
- **Restaurant Opening Trends**
